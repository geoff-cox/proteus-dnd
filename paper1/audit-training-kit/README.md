# Manual-audit training kit (protocol §8 and §11; kit v1.1)

The training packets of `docs/dnd/planning/paper1-manual-audit-protocol.md`
§11 (T1, T2) and of its 2026-10-15 "Training supplement" §12 line (T3, T4;
kit v1.1), as drawn by `proteus-audit-sample draw` (`proteus.paper1.audit_sample`)
from a database built from the regression fixtures only
(`src/tests/fixtures/golden_dnd_worked_example.tab`, `golden_dnd.tab` and
`golden_dnd_training_anomalies.tab`, boards from
`question_sources/sec-demo-shapes.ptx` through the real sync path). No student
data: the kit may be shared freely (§10, §11). Generated by
`proteus-audit-kit build --out <this folder>` (`proteus.paper1.audit_training_kit`);
`src/tests/test_audit_training_kit.py` rebuilds it and compares. How to train,
check and record: `docs/dnd/planning/paper1-audit-handbook.md`. This folder sat
at `docs/dnd/planning/paper1-audit-training-kit/` until 2026-10-27, when it moved
to `paper1/` at the repository root with the board-identity witness
(`cc-task-public-export` PR 2, ruling R2 (a)): data the frozen run and the
tests read, exported with the public pipeline.

The training record — the two passing sheets and the check report of
2026-10-15 on T1 and T2 — is `docs/dnd/records/audit-training-2026-10-15/`.

**The two commands**, from the repository root; `build` first, on the machine
that checks, because the scorer refuses a database whose hash is not the
manifest's and the database is not committed:

```
proteus-audit-kit build --out paper1/audit-training-kit
proteus-audit-kit check --out paper1/audit-training-kit \
    --sheet A=/path/to/the/returned/reviewerA-sheet.csv \
    --sheet B=/path/to/the/returned/reviewerB-sheet.csv
```

A rebuild reproduces every committed file under `training/` and `draw/` byte for
byte except `draw/sealed/draw_manifest.json` (path, hash, timestamp). `check`
writes the scorer's `audit-results.md` and `disagreements.csv` into `draw/`,
where they are gitignored.

**Never regenerate by hand to make a test pass.** A difference between a fresh
build and the committed kit means the replay of a frozen fixture changed (the
DnD golden rule) or the protocol's training section or its supplement was
amended — and an amendment is a dated §12 entry first.
